# Scenarios from real repositories

Each directory here is a small repository in the shape of one atlas was run on: the same frameworks, the same way of
writing routes and calls, the same configuration, with names and business logic replaced. `expected.yaml` holds what
that run showed once atlas read the code right, and `case` says what went wrong before. `test/scenarios.test.ts` runs
each one through scan, check, chains, flows and inventory, and compares everything exactly (the calls read and what each chain offers next too, where
`expected.yaml` lists them), so a change that moves any result shows as a difference in a case someone met.

| Scenario | Shape | What it pins down |
|---|---|---|
| `fastapi-react` | FastAPI backend, React client through an `authFetch` wrapper | a helper that registers POST, a StaticFiles mount (GET and an implicit HEAD), a mounted sub-application left unread with a limit, `{x:path}` not reaching the path without its segment where a route serves that path, inventory styles by language, a URL chosen between a base and none read as one call, a wrapper's default method declared in the configuration (GET, as fetch), a method the call states kept, a wrapper call of unread method left unmatched among routes of several methods |
| `fastapi-routers` | FastAPI backend of APIRouters gathered in one router the application includes under a settings prefix, a generated client | a router's prefix and its includes' joined to its routes, through a nested include and the imports naming the routers; the settings prefix declared in `mounts`; a router under an f-string prefix and one included nowhere left out with a limit each |
| `nest-versioned` | Nx NestJS API under a global prefix and URI versioning, an Angular client | the prefix and `v<version>` from the bootstrap found in the component, `@Version` on a method, a controller's version list, `VERSION_NEUTRAL`, literal `exclude` paths and RouteInfo (an excluded route keeps its version), `exclude` entries built at run time named in a limit |
| `express-spring-twins` | the same API in Express and Spring, a k6 load script as client | Express routers served only under a literal or declared mount path; an undeclared one left out with a limit, as is a route on a path the file does not spell out |
| `express-chained-routers` | an Express API in a standalone Nx workspace, its routers built by chaining `use` | a chain of `use` calls as the router it starts from, exported in place and mounted with `app.use(routes)`; `express.static` named in a limit; the Nx project as the component |
| `nextjs-app` | a Next.js app whose browser code calls its own route handlers | route handlers as surfaces, the HEAD and OPTIONS Next.js answers itself, no cycle for a component calling itself |
| `nextjs-pages` | a Next.js app whose pages link to each other, and a client of one route handler | pages as GET surfaces, links and share-link helpers reaching them, a literal type that is no request |
| `nextjs-content` | a Next.js App Router site at the repository root (`path: .`): marketing pages beside a catch-all, an editor under a dynamic segment, robots.ts, sitemap.ts, public/ files, a middleware | a link with a value in its path not reaching the catch-all Next.js serves after the dynamic segment, public files served before dynamic routes, a middleware matcher that is no request, both branches of a link as GET, metadata routes at their fixed paths, the links a page's server components and layouts render offered as `next` |
| `flutter-spring` | a Flutter app on Dio, a Spring backend under `/api/v1` | verbs with type arguments and paths on the next line, a declared client prefix, call files narrowed to the code that calls Dio, no components from the app's Android host |
| `spring-modulith-groups` | one Spring Boot application whose Spring Modulith modules are the components, springdoc with two groups | the default document and one per `GroupedOpenApi` group, found from the build file and beans outside the modules, shared by every module, left ambiguous |
| `ts-monorepo-bases` | Kotlin app → BFF → core service → file service, and a Python agent | URLs built on a `const` base, f-string URLs, route registrations that are no requests, `res.send()` that names no port, a journey whose order only the flow states, event streams on paths held in consts named in limits, a Kotlin exception given the path it reports on that is no request |
| `nx-angular-nest` | an Nx workspace: a Nest API, an Angular client and a library of HttpClient services | another host chosen in a template's leading hole named in a limit, as the same branches written as a whole conditional are |
| `fastapi-openapi-client` | FastAPI read from its generated document with its own operationIds, React on a generated @hey-api/openapi-ts client | `/users/me` reaching the concrete route only, the client's functions no app code calls left out with a limit, operations whose handler no rule finds named in a limit |
| `drf-openapi-client` | Django REST framework read from drf-spectacular's document, React on a generated client and two requests written by hand | the client's unused functions left out, a GET without the router's trailing slash matched, a POST without it matched to none with a limit |
| `spring-thymeleaf-pages` | a Spring MVC application whose Thymeleaf templates are its client, in the shape of Spring's sample application | quoted and appended link bases, preprocessed values, a route serving `.html`, page-relative links and forms with no action resolved against each page that renders them, view names in constants and private methods, `redirect:` replies as the next request, fragment parameters and a fragment file's form named in limits |
| `react-router-spa` | a Django REST backend described by its OpenAPI document, a React app on React Router calling it through a generated client | `Link`, `NavLink`, `navigate()` and route definitions as the app's own routes, no requests; `redirectDocument()` and an `<a href="/">` as GETs; no Next.js pages offered for a package that does not depend on next |
| `tanstack-router-spa` | a FastAPI backend, a React app on TanStack Router with file-based routes, every source file a call file | `createFileRoute`, `Link to`, `navigate({ to })`, `redirect({ to })` and the generated route tree as no requests; `window.location.href = url` as a GET |
| `react-router5-pages` | a Koa API under /api; a React app on React Router 5 with its `Route` passed on by a module of its own, wrapped by Sentry; a React front on React Router 7 with Lingui and a documentation site's address in a shared package | a `Route` followed through the module that exports it, `Redirect`, `useHistory`, `useRouteMatch`, paths listed and tested, a const followed to a `Redirect`, a Lingui message, a placeholder, legacy paths mapped into `<Route path>`, a path given to a function that joins it to another host, page paths a function or an object's methods return to routes and navigations, in its file or the files that import it: none is a request; a base held in a value named in a limit; a helper's path also used as a form's action, or put in a React context value, still read |
| `text-client-strings` | a Flutter app (Dart) on a NestJS server under /api, an ASP.NET Core web app forwarding to a catalog API described by its document | `endsWith` and `replaceFirst` arguments, an InputDecoration's `prefixText`, a `.log` file path, `UseExceptionHandler`'s path and a forwarder's route: none is a request; the forwarder's destination is read as a request to the catalog API |
| `ts-client-strings` | a mobile BFF adapter, a desktop app and its local companion server, a tool whose helper puts `/api/v1` before each path | a path passed to a helper as a label, compared or tested, a `path` option holding a file path, a link to another site, the helper's own `` `/api/v1${path}` ``: none is a request; a loopback URL is |

To add one: reproduce the shape in a new directory with an `atlas.config.yaml` (and `flows/` if the case is about
flows), run it, check every line of the result against the real repository, and write `expected.yaml`. A scenario that
only passes because its expected result was copied from the output proves nothing.
